# DNF70 单机一键端 · 上手教程

给你和朋友玩的**纯单机**版本：服务端、GM 控制台、登录器都在包里，不联网、不校验账号。
整包分两个压缩文件（客户端太大，分开传）：

| 压缩文件 | 内容 | 大概体积 |
|---|---|---|
| `DNF70-单机服务端与登录器-*.zip` | 服务端（只有编译好的 exe 和数据表，没有源码）＋ 登录器 ＋ 干净存档 ＋ 本教程 | 约 30 MB |
| `DNF70-干净客户端-*.zip` | 游戏客户端本体（`地下城与勇士` 文件夹） | 约 3.5 GB |

## 一、环境要求

- Windows 10 / 11 64 位（Win11 自带 WebView2；Win10 若打不开登录器窗口，装一下微软的 WebView2 运行时）。
- 磁盘留 8 GB 以上（客户端解压后约 4 GB）。
- 不需要联网，不需要任何账号。
- 杀毒软件可能把没签名的 exe 报毒：服务端/登录器都是自己编译的，误报请加白名单或信任目录。

## 二、安装（解压两次）

1. 把 `DNF70-单机服务端与登录器-*.zip` 解压到任意位置，比如 `D:\DNF70单机\`。
   解压后会得到文件夹 `DNF70-单机包\`，**里面第一个东西就是 `launcher-70s3a3.exe`**。
2. 把 `DNF70-干净客户端-*.zip` 解压**进上面那个文件夹里**，让它变成：

```
DNF70-单机包\
├─ launcher-70s3a3.exe        ← 一切从这里进
├─ 单机教程.md
├─ Server-70s3a3\             ← 服务端（exe + 数据表）
└─ local-run\
   ├─ DNF70-batch-test-FG\    ← 你的存档（想备份就拷走这整个文件夹）
   └─ seed-store\             ← 出厂存档备份（玩坏了用它还原）
DNF70-单机包\地下城与勇士\     ← 客户端解压到这里（和 launcher 同级目录里面）
```

> 客户端文件夹必须叫 `地下城与勇士`，且放在 `DNF70-单机包\` 里面；登录器靠这个结构自动认路。
> 路径里可以有中文，但**不要带空格**，省得各种奇怪问题。

## 三、第一次启动

1. 双击 `launcher-70s3a3.exe`。
2. 在「服务端」页点 **一键启动服务端**，等顶部两盏灯变绿：`频道 7002`、`入口 17001`
   （第一次会慢几秒；灯不亮就看页面里的"说明"一行，多半是端口被占，见常见问题）。
3. 点 **启动游戏客户端**。游戏窗口起来后：选频道 → 进入 → 角色选择界面。
4. 包里自带一个 1 级角色 `yoyo`。想用自己的名字就在角色选择界面**创建新角色**
   （九个职业都能建：鬼剑士/格斗家/神枪手/魔法师/圣职者/女枪手/暗夜使者/女格斗家/女魔法师，最多 17 个）。
5. 进城镇之后就可以玩了。回到登录器点「刷新」，角色页会显示你当前角色的等级、金币、背包、任务。

## 四、GM 控制台（单机版的乐趣所在）

登录器左侧「角色」页：

- **GM 目标角色**：下拉或点名册里的行，选你要操作的角色。服务端空闲时会立刻切过去；
  如果你人还在游戏里，服务端只认游戏里选的那个角色，登录器会提示并暂时禁用写入按钮——
  想换目标就先把游戏退到角色选择界面。
- **设置等级**：1–70 随便填，按该等级的门槛经验写满。
- **发放点券**：加的是**账号点券**（服务端 FG271 起，商城和合约扣的就是这一笔），发给谁同账号所有角色都能用；
  出厂存档本身带 **1 万点券**和 6 件初始物品，那是服务端建号时给的，不用自己发；代币券是绑定币，本服务端没有发放线路，只能看余额。
- **转职 / 换分支 / 觉醒**：按钮按当前职业显示。鬼剑士是 剑魂/鬼泣/狂战士/阿修罗，女魔法师只有
  元素爆破师/冰结师 两个（这套脚本里她就这两条转职线）。没转职时按钮是"转职"，已转职后变成"换到 X"——
  换分支会把技能点**全部退回**、觉醒清零，然后按新分支重新发一次转职赠技，等级/金币/任务都不动。
- 「任务」页：列出已接任务，点一行再点「完成选定任务」，服务端按任务表正常结算奖励
  （经验/金币/物品/称号都真给）。缺提交物时勾「自动补齐提交物」。
- 「道具」页：按物品 ID 或类型检索发放，名字是从 PVF 现读的（没起 pvfUtility 就只显示 ID）。
  发**装备类**物品时可以顺带写：强化等级（+0..+31）、品质种子、再封印次数（0..7，仅武器/装备）、是否封印。
  这套引擎没有"增幅"这个数据字段（增幅属性在原版是另一套机制，本服务端未实现），所以界面不提供、也别去改。
- 「副本」页：一键清图（游戏里进副本后按，一个房间按一次）、自动拾取开关；
  「设置」页可以给一键清图绑全局快捷键，游戏窗口在前台也能按。
- 「角色」页还有**恢复满疲劳**：一键把当前目标角色的疲劳回满 156 点（黑钻额外疲劳的当日用量同时清零），
  角色在副本里时服务端会要求先回城再恢复。

> 所有 GM 操作都走服务端自己的结算逻辑，不是改内存：发多少就是多少，任务奖励按任务表给。

## 五、存档备份与还原

- 存档 = `local-run\DNF70-batch-test-FG\` 整个文件夹。想备份就关掉服务端后拷走。
- 玩坏了想重来：关掉服务端，删掉 `DNF70-batch-test-FG\` 文件夹，
  把 `local-run\seed-store\` 复制一份改名为 `DNF70-batch-test-FG` 即可回到出厂的 1 级 yoyo。

## 六、常见问题

- **登录器双击没反应 / 白窗**：缺 WebView2（Win10 常见），装微软官方的 WebView2 运行时。
- **"端口 7002 或 17001 已被占用"**：上一轮服务端没退干净，或别的程序占了。
  先在「服务端」页点「停止服务端」；还不行就在「设置」页把两个端口改成 17000–17999 里别的数（两个不能相同），保存后重试。
- **游戏里连不上 / 一直转圈**：确认登录器上 `频道 7002` 灯是绿的再进游戏；顺序永远是先起服务端、再开客户端。
- **杀软报警**：误报。把 `DNF70-单机包` 整个目录加入白名单。
- **想给朋友传档**：只传 `DNF70-batch-test-FG` 文件夹即可，对方覆盖自己包里的同名文件夹。
- **改了客户端文件 / PVF 会怎样**：本包按原版客户端验证过，替换 PVF 或 exe 属于自行折腾，不在教程范围内。
